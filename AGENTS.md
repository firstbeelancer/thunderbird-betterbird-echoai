# AGENTS.md — EchoAI

Открытое бесплатное расширение (MailExtension, Manifest V3) для **Betterbird / Mozilla Thunderbird**: персональный ИИ-ассистент для работы с почтой через любые OpenAI-compatible API с прямым голосовым вводом в мультимодальную LLM.

Все проектные заметки, архитектурные решения и правила разработки ведутся здесь и в `TZ.md`.

---

## Главное правило: никаких секретов в репозитории

**Ни в коем случае не допускать попадания ключей и личных данных в репозиторий** (код, документы, примеры, скриншоты, имена файлов, сообщения коммитов):
- API-ключи, токены, пароли, приватные ключи (`sk-`, `ghp_`, `github_pat_`, `AKIA`, и т.п.);
- `.env`, дампы профилей Betterbird, реальные адреса почты, тексты личных писем.

### Обязательная проверка перед каждым коммитом / публикацией
1. Поиск секретов по всему дереву (кроме `dist/`): `api[_-]?key`, `secret`, `password`, `ghp_`, `github_pat_`, `sk-`, `AKIA`.
2. Проверка валидности манифеста: `python -m json.tool extension/manifest.json`.
3. Сборка пакета `.xpi`: `python tools/pack-extension.py` → `dist/echoai-<версия>.xpi` (файл `manifest.json` строго в корне архива).

Если найден ключ или секрет — не коммитить, удалить из файлов и истории, предупредить Марину о необходимости перевыпустить ключ.

## Принцип работы расширения («Только по вызову»)

- **Zero Background Activity:** расширение **никогда** не сканирует почтовый ящик в фоне, не индексирует переписку, не делает автоматических запросов при открытии писем или запуске клиента.
- Все запросы к API выполняются исключительно по явному действию пользователя.
- Вся конфигурация (URL, ключи, модели, промпты) хранится только локально в `browser.storage.local`.

## Дизайн-система и правила UI

**Жёсткое правило: красивый, сдержанный, «вкусный» нативный UI — никакого нейрослопа и никаких эмодзи.**

- **Ноль эмодзи в UI:** везде (кнопки, меню, статусы, аудио-чипы, уведомления, настройки) используются **исключительно чистые векторные линейные SVG-иконки** (`stroke="currentColor"`, `stroke-width="1.75"`, `stroke-linecap="round"`, `stroke-linejoin="round"`).
- **Никаких клише «AI-слопа»:** никаких фиолетово-розовых градиентов, «магических звёздочек-спарклов» повсюду, неоновых свечений и визуального шума.
- **Эстетика:** вдохновлена чистым десктопным софтом и референсом Марины:
  - Светлая тема: спокойный холодно-нейтральный фон (`#F3F6FA`), белые поверхности (`#FFFFFF`), мягкие деликатные границы (`#D6DFEA`), глубокий стальной синий акцент (`#2B5C96` / hover `#234B7B`), контрастный текст (`#182230`, вторичный `#5B6B7F`).
  - Тёмная тема: глубокий графитово-сланцевый фон (`#12171E`), карточки (`#1A212B`), тонкие границы (`#2B3645`), спокойный голубовато-стальной акцент (`#5B96D8`), читаемый текст (`#E8EEF5`, вторичный `#94A3B8`).
  - Контраст текста и контролов — не ниже **WCAG AA**.
  - Шрифт: `Inter` (при наличии) с системным fallback (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`).
- **Ключевые UI-паттерны:**
  - Кнопки-пилюли (`Copy`, счётчик токенов `1 581 tokens` с раскрывающейся детализацией, `Закрыть`).
  - Кнопка `Copy` у **каждой** реплики в диалоге (и пользовательской, и ответа ИИ).
  - Живая, плавная анимация статуса модели (*Отправляю запрос… → Думает… → Печатает ответ…*) без показа сырых рассуждений (`reasoning_content` / `<think>` скрываются, но переводят статус в «Думает…»).

## Технические заметки по Betterbird / Thunderbird

- **Совместимость:** `strict_min_version: "128.0"` (покрывает Thunderbird 128/140 ESR и соответствующие релизы Betterbird).
- **Нормализация URL API:** пользователь может вставить `https://clodex.xyz`, `https://clodex.xyz/v1` или `https://clodex.xyz/v1/chat/completions` — клиент всегда нормализует к единому базовому пути без дублирования `/v1`.
- **Голосовой ввод:** в Gecko нет Web Speech API (`SpeechRecognition`), а в Thunderbird/Betterbird отсутствует браузерный диалог WebRTC (`webrtcUI.sys.mjs`) и страницы расширения часто выполняются в отдельном дочернем процессе (`extension`). Поэтому в `extension/api/mic/` разделены `echoMicParent` (`addon_parent` — нативный диалог подтверждения строго для EchoAI с сохранением в `Services.perms` и кратковременным scoped-bypass строго на один вызов, если child-observer не перехватил запрос) и `echoMicChild` (`addon_child` — перехват `getUserMedia:request` в том же процессе и ответ `getUserMedia:response:allow`). Запись кодируется в **WAV (PCM 16-bit, 16 kHz, mono)** и отправляется через `input_audio` напрямую в `/v1/chat/completions`.
- **Сохранение HTML-подписи Betterbird:** при вставке/замене текста в окне создания/ответа письма обязательно сохранять `<div class="moz-signature">` (HTML-подпись) и цитату переписки (`<div class="moz-cite-prefix">`, `<blockquote>`) ниже вставленного текста.
- **Лицензия:** открытый бесплатный проект (уточнить/подтвердить тип лицензии, например MIT, перед добавлением файла `LICENSE`).
