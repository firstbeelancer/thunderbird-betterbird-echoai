# EchoAI

Открытое бесплатное расширение (Manifest V3) для **Betterbird** и **Mozilla Thunderbird** (128+ ESR): персональный ИИ-ассистент для работы с почтой через любые OpenAI-compatible API с прямым голосовым вводом в мультимодальную LLM.

## Основные возможности

- **Работа строго по вызову** — никакой фоновой активности, индексации или скрытого сканирования почтового ящика.
- **Чтение писем:**
  1. **Быстрый ответ** — сразу готовый ответ по всей переписке с кнопками «Вставить в ответ» и «Копировать».
  2. **Чат с ассистентом** — полноценный диалог текстом и голосом, копирование любой реплики, счётчик токенов с разбивкой, анимированный статус работы модели без сырых рассуждений.
  3. **Краткое саммари** — структурированная выжимка письма или всей ветки целиком.
  4. **Перевод** — быстрый перевод на выбранный язык.
- **Написание и редактирование писем («Создать» / «Ответить»):**
  1. **Улучшить текст** — перевод сырого или эмоционального черновика (выделенного фрагмента или всего текста) в этичный живой деловой стиль без канцеляризмов и без потери позиции.
  2. **Чат с ассистентом**, **Быстрый ответ**, **Краткое саммари**, **Перевод**.
- **Бережное сохранение HTML-подписи Betterbird** — при вставке и замене текста расширение не затрагивает вашу HTML-подпись (`moz-signature`) и цитату переписки ниже.
- **Прямой голосовой ввод без отдельного STT** — запись с микрофона локально кодируется в компактный WAV (16 kHz, mono) и отправляется через `input_audio` напрямую в мультимодальную модель (например, `gemini-4-hydrogen-high`).
- **Любые OpenAI-compatible провайдеры** — готовые пресеты (**Clodex**, **OpenRouter**, **CometAPI**, **OpenAI**, **Google Gemini**, **Custom API**), умная нормализация URL, загрузка списка моделей скопом + ручной ввод модели и обязательная кнопка **«Протестировать подключение»**.

## Установка в Betterbird / Thunderbird

1. Скачайте готовый файл `echoai-1.0.2.xpi` (из `docs/download/echoai-1.0.2.xpi` или соберите командой `python tools/pack-extension.py`).
2. В Betterbird / Thunderbird откройте **Дополнения и темы** → иконка шестерёнки → **Установить дополнение из файла…** → выберите `.xpi`.
3. Откройте настройки **EchoAI**, выберите провайдера (например, **Clodex**), вставьте API-ключ, выберите или введите модель и нажмите **«Протестировать подключение»**.

## Сборка из исходников

```bash
python tools/pack-extension.py
```

Собранный архив появится в `dist/echoai-1.0.0.xpi`.
