# EchoAI

Открытое бесплатное расширение для **Betterbird** и **Mozilla Thunderbird** (128+ ESR): персональный ИИ-ассистент для работы с почтой через любые OpenAI-compatible API с прямым голосовым вводом в мультимодальную LLM.

## Возможности

- **Работа строго по вызову** — никакой фоновой активности и скрытого сканирования писем.
- **Чтение письма:** Быстрый ответ, Чат с ассистентом, Краткое саммари (письма или всей ветки), Перевод.
- **Написание и редактирование письма:** Улучшить текст (выделенного фрагмента или всего черновика с бережным сохранением HTML-подписи Betterbird), Чат с ассистентом, Быстрый ответ, Краткое саммари, Перевод.
- **Полный контекст переписки** — ассистент видит всю цепочку реплик в хронологическом порядке.
- **Прямой голосовой ввод** — запись с микрофона в компактный WAV и отправка напрямую в мультимодальную модель без отдельных STT-сервисов.
- **Любые OpenAI-compatible провайдеры** — готовые пресеты (Clodex, OpenRouter, CometAPI, OpenAI, Google Gemini, Custom API), умная нормализация URL, загрузка списка моделей + ручной ввод и кнопка тестирования подключения.
